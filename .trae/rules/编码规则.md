禁止手动编辑wails自动生成的绑定文件（如App.d.ts）
每次更改完代码禁止自动commit，禁止自动push。
pre-commit hook（.githooks/pre-commit）自动跑验证，按 staged 文件分层触发：Go 改动跑 go build/go test/golangci-lint，前端改动跑 npm run build/lint/test，纯文档/配置跳过。无需手动验证。

## Commit 格式规范

所有 commit message 必须遵循 Conventional Commits 格式(不符合规范的会被git hook拦截)：

```
type(scope): description

body（可选，前面必须空一行）
```

type 固定以下 11 种（小写）：feat fix docs style refactor perf test build ci chore revert
scope 可选，大小写不限

## Git 写操作禁令

未经用户明确许可，禁止执行任何 git 写操作，尤其是：
- git commit（包括 --amend）
- git reset（任何参数）
- git revert
- git checkout（切换分支或恢复文件）
- git push
- git rebase
- git merge
- git stash（push/pop/apply/drop/clear）
- git branch -D/-M
- git tag -d
- git clean
- git remote add/remove/set-url

只允许执行只读 git 操作：log show diff status branch tag ls-* blame grep rev-parse rev-list stash\ list
